# Skill: Private Company Evaluation (draft placeholder)

No private-company positions or watchlist entries exist in `snestack.db` yet, even though the project's stated scope covers public and private companies. This file is a placeholder for when that changes.

Likely differences from the public-market skills once there's real content to model against:
- No ticker/quote/RSI data exists for a private holding, so `long-term-quality.md`'s technical add-on timing step doesn't apply at all.
- Valuation is thesis- and round-based (last round price, comparable multiples) rather than a Morningstar fair-value estimate.
- Liquidity horizon is much longer, and "exit" isn't a sell order — it's a secondary sale, acquisition, or IPO.
- Position sizing and risk tolerance for illiquid, binary-outcome bets are usually different from public-market sizing rules.

Don't guess at private-market judgment criteria the user hasn't actually stated. The next time a private company is being evaluated, flag this file and build it out from a real conversation about that specific deal, the way `long-term-quality.md` and `swing-trading-large-cap.md` were built from a real conversation about the public positions.
